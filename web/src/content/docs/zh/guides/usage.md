启动参数只决定**默认值**：打开*什么*、播放头从*哪里*开始。一旦跑起来，无论你怎么
启动的，回拖 / 跟随 / 暂停 / 回到直播全都可用。

## 启动（终端版）

```text
zoe                          跟随当前项目的实时会话
zoe <dir>                    跟随另一个项目的实时会话
zoe <file.jsonl>             从头回放一份录制，按节奏播放
zoe <file.jsonl> --follow    改为打开录制的直播边缘
zoe <file.jsonl> --speed N   回放倍速（默认 8.0）
zoe inspect <file.jsonl>     打印会话树后退出（无 TUI）
```

**文件**目标是批量加载后持续 tail；**目录**（或不带参数 → 当前项目）会发现最新的
会话并实时跟随。`--follow` 只改变播放头的起点（直播边缘而非开头）。

## 启动（浏览器版）

[浏览器版](/app)启动即进入内置演示。想看自己的会话：

- **会话**（Chromium 系浏览器）：点击**会话**浏览你的 Claude 项目，选一个并实时
  跟随。zoetrope 会读取主 transcript 加上它的子 agent，然后 tail 整个目录等待新
  活动。这与终端版“跟随正在运行的会话”是同一条流程，构建在 File System Access
  API 之上。什么都不会被上传。
- **会话**（其他浏览器）：同一个按钮会退回到文件夹选择器，所以浏览和回放在哪里都
  能用。**实时跟随不行**——没有 File System Access API 时，浏览器交出的是每个文件
  不可变的*快照*，选择之后发生的写入永远到不了。选择器会在你选择之前说明这一点。
  实时跟随需要 Chrome 或 Edge（或终端版 TUI）。
- **拖放**一份 `.jsonl` transcript（任何浏览器）。拖放只携带你拖进来的东西，而
  transcript 里没有任何指向侧车文件的引用——所以要把 `<uuid>.jsonl` **和**它的
  `<uuid>/` 文件夹一起拖，才能带上子 agent 和工作流。只拖 transcript 的话你只会看到
  主 agent；zoetrope 会明说，而不是假装这个会话没有子 agent。

## 按键

| 按键 | 作用 |
| --- | --- |
| <kbd>space</kbd> | 播放 / 暂停（从播放头处继续） |
| <kbd>[</kbd> / <kbd>]</kbd> | 跳到上一个 / 下一个提示词段 |
| <kbd>End</kbd> / <kbd>g</kbd> | 跳到直播边缘 |
| <kbd>s</kbd> | 切换跳过空闲段（压缩死时间 ↔ 实时） |
| 鼠标拖动 | 沿进度条定位 |
| <kbd>o</kbd> / <kbd>f</kbd> | 镜头：总览 / 跟随 |
| <kbd>r</kbd> | 重新布局（整理图表） |
| 方向键 / <kbd>Tab</kbd> / <kbd>shift-Tab</kbd> | 在 agent 之间移动 |
| <kbd>h</kbd> <kbd>j</kbd> <kbd>k</kbd> <kbd>l</kbd> | 平移图表 |
| <kbd>+</kbd> / <kbd>-</kbd> / <kbd>0</kbd> | 放大 / 缩小 / 复位 |
| <kbd>c</kbd> | 居中到选中的 agent |
| 点击 | 打开 agent 的详情面板 |
| <kbd>j</kbd> / <kbd>k</kbd> / <kbd>PgUp</kbd> / <kbd>PgDn</kbd> | 滚动详情面板 |
| <kbd>i</kbd> | 会话信息浮层 |
| <kbd>L</kbd> | 切换界面语言 |
| <kbd>?</kbd> | 帮助浮层 |
| <kbd>esc</kbd> | 关闭浮层 / 清除选中 |
| <kbd>q</kbd> / <kbd>ctrl-c</kbd> | 退出（终端版） |

选中 agent 时 <kbd>j</kbd> / <kbd>k</kbd> 滚动详情面板，否则平移图表。

### 鼠标操作

上表几乎每项都有按键，但鼠标会让大多数操作更自然——而且**拖动进度条是纯鼠标
操作**：它是唯一没有键盘等价物的交互（按键是逐段跳，拖动是连续定位）。滚轮缩放也
与 <kbd>+</kbd>/<kbd>-</kbd> 不同：它以指针位置为锚点，而不是视口中心。

拖空白画布平移 · 滚轮以指针为中心缩放 · 点 agent 看溯源 · 拖进度条穿越会话。四项
操作在[首页各有一段录像](/zh/#)。

## 传输状态

zoetrope 从不存储“模式”。传输徽章是从播放头相对直播边缘的位置*推导*出来的：

- **直播：** 正跟随边缘，且有新内容正在到达。
- **播放：** 按节奏回放，在已缓冲的事件中前进。
- **已暂停：** 按节奏回放，被 <kbd>space</kbd> 停住。
- **回看：** 停在过去，从边缘回拖。
- **空闲：** 在边缘但没有新活动，比如已结束或安静的会话。

## 会话信息

按 <kbd>i</kbd> 打开会话浮层：模式、权限模式、排队操作、文件编辑和最近的提示词。
这些数据不进时间线，只在你要求时显示。同样的数据可以无界面地通过
`zoe inspect <file.jsonl>` 获得。

## 界面语言

界面默认跟随系统语言（终端读 `LANG`/`LC_ALL`，浏览器读
`navigator.language`），也可以显式指定：启动时加 `--lang zh`（或
`ZOETROPE_LANG` 环境变量），运行中按 <kbd>L</kbd> 在语言之间循环切换。目前提供
英文和简体中文；`zoe --help` 的用法说明同样会按语言输出。
